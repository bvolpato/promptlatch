P PromptLatch LOCAL

Request inspector

Inspect sessions, request payloads, and performance on your server.

On the server, the token is usually available with:

cat ~/.local/state/promptlatch/requests.sqlite3.dashboard-token

For custom locations, use the token file path printed at server startup.

The dashboard token is exchanged for an HttpOnly browser session that expires 30 days after sign-in. PromptLatch does not retain the token in browser storage. Request bodies and upstream error details are redacted before storage. Full response bodies are not stored.
